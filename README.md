# Alo.bg Auto-Bump

Автоматизация ежедневного поднятия объявлений на сайте [alo.bg](https://www.alo.bg/).

## Описание

Этот проект автоматизирует процесс поднятия объявлений на сайте alo.bg. Скрипт:

1. Авторизуется на сайте alo.bg
2. Переходит в раздел "Мои объявления"
3. Для каждого активного объявления нажимает кнопку "Направи първа безплатна"
4. Подтверждает действие в диалоговом окне
5. Формирует отчёт о выполненных действиях
6. Отправляет отчёт в Telegram через бота

## Требования

- Python 3.10 или выше
- Playwright браузер (устанавливается автоматически)

## Установка

1. Клонируйте репозиторий или скопируйте файлы проекта

2. Создайте и активируйте виртуальное окружение:

   **Windows:**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

   **Linux/macOS:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

   После активации виртуального окружения в начале строки терминала появится `(venv)`.

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Установите браузеры для Playwright:

```bash
playwright install chromium
```

5. Создайте файл `.env` на основе `.env.example`:

   **Windows:**
   ```bash
   copy .env.example .env
   ```

   **Linux/macOS:**
   ```bash
   cp .env.example .env
   ```

6. Заполните `.env` файл своими данными:

```env
ALO_LOGIN=your_email@example.com
ALO_PASSWORD=your_password
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_telegram_chat_id

# Browser settings
# Set to "true" to run browser in headless mode (no window), "false" to show browser window
# Default: true
BROWSER_HEADLESS=true
```

### Получение Telegram бота и Chat ID

1. **Создание бота:**
   - Найдите [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Сохраните полученный токен в `TELEGRAM_BOT_TOKEN`

2. **Получение Chat ID:**
   - Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
   - Отправьте любое сообщение боту
   - Бот вернёт ваш Chat ID
   - Сохраните его в `TELEGRAM_CHAT_ID`

## Настройка браузера

По умолчанию браузер запускается в headless-режиме (без окна). Чтобы видеть процесс выполнения в браузере, установите в файле `.env`:

```env
BROWSER_HEADLESS=false
```

Для скрытого режима (рекомендуется для автоматического запуска):
```env
BROWSER_HEADLESS=true
```

2. Зависимости установлены в виртуальное окружение (выполните `pip install -r requirements.txt` после активации)

## Автоматический запуск (Cron / Docker)

### Развёртывание на VPS Ubuntu (без Docker)

**📖 Подробная инструкция по развёртыванию на сервере Ubuntu доступна в файле [DEPLOYMENT_UBUNTU.md](DEPLOYMENT_UBUNTU.md)**

Эта инструкция включает:
- Пошаговую настройку сервера
- Установку всех зависимостей
- Настройку cron для ежедневного запуска в 9:00 по времени Софии
- Устранение неполадок
- Рекомендации по безопасности

### Быстрая настройка Cron (без Docker)

Для ежедневного запуска в 09:00 по времени Софии добавьте в crontab:

**Linux/macOS:**
```bash
0 9 * * * cd /path/to/alo_auto_bump && /path/to/alo_auto_bump/venv/bin/python main.py >> /path/to/alo_auto_bump/logs/cron.log 2>&1
```

**Windows (Планировщик заданий):**

1. Откройте "Планировщик заданий"
2. Создайте новое задание
3. Установите триггер: ежедневно в 09:30
4. Действие: запуск программы `venv\Scripts\python.exe` с аргументами `main.py`
5. Рабочая папка: путь к проекту

**Примечание:** В планировщике задач используйте полный путь к Python из виртуального окружения, например: `D:\path\to\alo_auto_bump\venv\Scripts\python.exe`

### Автозапуск через Docker

Для деплоя на сервер с Docker и настройки автозапуска в 9:30 по времени Софии используйте инструкцию в файле `DOCKER.md`. Там описаны:

- сборка Docker-образа;
- разовый запуск контейнера для проверки;
- варианты расписания (cron на хосте, systemd timer, cron внутри контейнера).

## Логирование

Логи сохраняются в файл `logs/alo_auto_bump.log` и выводятся в консоль. Файлы логов ротируются при достижении 10MB (сохраняется до 5 резервных копий).

## Отчёты

После каждого запуска скрипт отправляет отчёт в Telegram, содержащий:

- Дата и время выполнения (в часовом поясе Europe/Sofia)
- Количество обработанных объявлений
- Количество успешно поднятых объявлений
- Количество пропущенных объявлений
- Детальная информация по каждому объявлению

### Статусы объявлений

- **Обновлено** — кнопка «Направи първа безплатна» нажата, результат подтверждён (кнопка исчезла или стала неактивной).
- **Уже обновлено сегодня** — сайт сообщил, что объявление уже обновлялось.
- **Не подтверждено (кнопка осталась)** — после нажатия кнопка осталась активной и диалог не распознан; успех не засчитывается. Если подряд 3 объявления не подтверждены, прогон останавливается (вероятно, сайт изменился), отчёт всё равно отправляется.
- **Пропущено: платный диалог, не нажато** — в диалоге подтверждения найдены признаки платной услуги (лв, €, eur, SMS, VIP, ТОП и т. п.); кнопка не нажимается.

Защита от зацикливания: максимум `2 * N + 5` итераций (N — число объявлений в начале прогона), при превышении останавливается и приходит сообщение об ошибке.

### Лимит времени и диагностика

- `MAX_RUN_MINUTES` (в `.env`, по умолчанию 60) — общий лимит времени одного запуска; по истечении запуск прерывается, браузер закрывается, в Telegram приходит ошибка.
- При первом «не подтверждено» за запуск в `logs/` сохраняются `bump_unconfirmed_<дата_время>.png` (скриншот) и `bump_unconfirmed_<дата_время>.html` (HTML страницы); текст видимых диалогов пишется в лог.

## Устранение неполадок

### Проблемы с установкой зависимостей

**Ошибка "Failed to build wheel for greenlet":**

Эта ошибка возникает на Windows при использовании Python 3.13 и старой версии Playwright. Решение:

1. Убедитесь, что используется обновленная версия Playwright (>=1.48.0) в `requirements.txt`
2. Обновите pip, setuptools и wheel:
   ```bash
   pip install --upgrade pip setuptools wheel
   ```
3. Если проблема сохраняется, установите Microsoft Visual C++ Build Tools:
   - Скачайте с https://visualstudio.microsoft.com/visual-cpp-build-tools/
   - Или используйте Python 3.11/3.12 вместо 3.13

### Проблемы с авторизацией

Если скрипт не может войти на сайт:

1. Проверьте правильность логина и пароля в `.env`
2. Убедитесь, что сайт alo.bg доступен
3. Проверьте логи в `logs/alo_auto_bump.log`
4. При неудачном входе бот отправляет в Telegram причину (URL, заголовок страницы, текст ошибки, наличие капчи) и сохраняет `logs/login_verification_failed.png` и `logs/login_verification_failed.html`

### Предупреждение «Не найдено ни одного объявления»

Если в Telegram пришло такое сообщение, бот открыл страницу «Мои объявления», но не нашёл кнопок поднятия. Если в сообщении написано «Похоже, бот не вошёл в аккаунт», проверьте вход (см. выше). Иначе проверьте, есть ли активные объявления на сайте. Диагностика сохраняется в `logs/no_ads.png` и `logs/no_ads.html`.

### Проблемы с поиском кнопок

Если кнопки "Направи първа безплатна" не находятся:

1. Структура сайта могла измениться
2. Проверьте логи для детальной информации
3. Возможно, потребуется обновить селекторы в `app/alo/actions.py`

### Проблемы с Telegram

Если сообщения не отправляются:

1. Проверьте правильность `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
2. Убедитесь, что бот запущен (отправьте `/start` боту)
3. Проверьте интернет-соединение
